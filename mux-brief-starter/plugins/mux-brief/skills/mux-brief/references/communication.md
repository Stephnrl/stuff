# Communication and knowledge briefs

Use only when the task is to create instructions for another assistant to produce a message, document, summary, or analysis.

State the intended recipient, purpose, and the specific evidence/input the recipient assistant should rely on. Indicate whether external facts need citations; never demand invented sources.

Focus on measurable output such as a ready-to-send email, a two-paragraph memo, or a decision comparison. Do not wrap a simple writing task in software engineering language.

When the user supplies a document or transcript, tell the receiving agent to treat it as source material, identify open questions, and distinguish quotes from interpretation. Do not assume persistent memory across sessions.
